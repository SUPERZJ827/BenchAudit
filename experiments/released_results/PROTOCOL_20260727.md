# Released-result evidence protocol

This experiment asks whether already-published model outputs and evaluator
verdicts can cheaply identify high-value benchmark audit candidates before any
new model or agent execution.

## Inputs

- SQLBench SQL Dialect Translation model outputs and SQLGlot 30.2.1 sidecars.
- PortugueseSpider structural-match and database-execution score files.
- DBCode PostgreSQL/SQLite outputs, full-harness results, and function-test
  results.

Every consumed source file is recorded with byte length and SHA-256. Records
are aligned by an explicit item ID, a published task digest, or a digest of
the exact `(reference, prediction)` pair. Row position is not used to join
independent files.

## Evidence policy

1. Historical outputs and published verdicts are observations, not defect
   ground truth.
2. Reference-integrity, evaluator-disagreement, and version-drift candidates
   are dataset-level and review-only.
3. The central promotion policy caps all released-result/trace-derived
   provenance at `review`, even if a caller renames the detection method.
4. A syntax replay reproduces a published evaluator result but does not prove
   semantic correctness or complete dialect support.
5. Confirmation requires an independently reconstructed task/evaluator or a
   deterministic verifier whose prerequisites are independently established.

## Quantitative outputs

- coverage: files, systems, items, runs, missing channels;
- evaluator contingency tables and disagreement rate with Wilson interval;
- model-ranking sensitivity across evaluator choices;
- SQL reference diagnostics and published reference-evaluator failures;
- cheap-signal ablation against the *published parser-failure proxy*:
  prediction failure rate, literal diagnostic detection, and their fusion;
- deterministic random-ranking control;
- stable manifest and summary hashes;
- pinned SQLGlot 30.2.1 replay and mismatch count.

The parser-failure proxy is explicitly not semantic ground truth. The 65 known
literal diagnostic references are used as a case study/regression target, not
as an unbiased hidden test set.
